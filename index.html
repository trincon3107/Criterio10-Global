Ready. Payoffs are interpreted as profits/benefits, so higher values are better.

2. Decision model

Edit alternative names, state names, payoffs, and probabilities directly in the table. Probabilities must be between 0 and 1 and add up to 1. Use decimal notation (for example, 0.25 = 25%).

3. Decision criteria

Maximax chooses the highest possible payoff. Maximin chooses the best worst-case payoff. Minimax Regret minimizes the maximum opportunity loss. EMV/Bayes chooses the highest probability-weighted expected payoff.

4. Staged filtering

This dashboard uses a transparent three-stage filter: (1) remove alternatives that are not optimal under Maximax; (2) among survivors, keep those with the highest Maximin; (3) among survivors, keep those with the highest EMV. Ties are retained at every stage.

5. Staged-filtering flow diagram

The final box shows the alternative(s) remaining after all three filters. If several alternatives tie, all are retained.
